How to Fix Windows Update Stuck or Failing

Short answer: first give the update time, because a percentage that looks stuck is often still working in the background. If it has truly stalled for hours, restart the PC, run the Windows Update troubleshooter, and then clear the update cache and try again. Only as a last resort should you download the update manually or reinstall Windows, and you should back up your files before either of those steps.

First: is it really stuck?

Large Windows updates can sit at the same percentage for a long time, especially on a slow hard drive or a slow connection, and the hard drive light or network activity may still show work happening. Before doing anything, wait at least an hour for a normal update and two hours for a major feature update, with the PC plugged into power and connected to the internet. Do not hold the power button during an update unless the PC is completely unresponsive for several hours, because switching off mid-update is one of the few things that can genuinely corrupt the installation.

1. Restart properly

If the update is still stuck after a generous wait, restart through the Start menu if you can, or hold the power button only if the PC will not respond at all. After the restart, Windows often rolls the update back and boots normally, which is a safe outcome, not a disaster. Once back on the desktop, open Settings, then Windows Update, and check the history to see which update failed and whether an error code is shown. Write the error code down: it makes every later search and support request much faster.

2. Run the Windows Update troubleshooter

Windows includes a troubleshooter built for exactly this problem. Go to Settings, then System, then Troubleshoot, then Other troubleshooters, and run Windows Update. Let it finish, apply any fix it suggests, and restart if it asks you to. This tool checks the update service, resets its settings and fixes common permission problems, and it solves a surprising number of repeated failures on its own. If it reports that it could not identify the problem, move on to the next step rather than running it again and again.

3. Free up space and check your connection

Updates fail when the drive is nearly full. Aim for at least 20 GB free for a major update, and more if you can manage it. Delete large files you no longer need, empty the Recycle Bin, and uninstall apps you never use — our Windows speed-up guide covers the safe cleanup steps in detail. Also make sure you are not on a metered connection, which pauses downloads, and try a wired connection or a stronger Wi-Fi signal if downloads keep failing halfway. A VPN or a strict firewall can also block update servers, so try temporarily disabling them for one update attempt.

4. Clear the update cache

A corrupted download is a common cause of an update that fails at the same point every time. The fix is to stop the Windows Update service, delete the contents of the SoftwareDistribution download folder, and restart the service so Windows downloads a fresh copy. To do this safely, search for Services, stop Windows Update, open C:\Windows\SoftwareDistribution\Download, delete its contents — not the folder itself — then start the service again and check for updates. Do not delete other Windows folders, and do not use a registry cleaner for this problem: the cache clear is enough in most cases.

5. Update drivers and pause, then retry

Outdated storage, graphics or chipset drivers can block an update, so check Windows Update, then Optional updates, for driver updates, and visit your PC maker's support page for the latest drivers for your exact model. If a specific update keeps failing, you can pause updates for a week from Settings, then Windows Update, and try again after a restart — sometimes Microsoft fixes a faulty update within days. Pausing is better than disabling updates permanently, because unpatched systems miss security fixes and eventually run into bigger problems.

6. Download the update manually

If the same update still fails, try the Microsoft Update Catalog: search for the update's KB number, download the version that matches your system, and install it by double-clicking the file. For a feature update, Microsoft's Windows Installation Assistant or Media Creation Tool can install the new version while keeping your files, but back up your important documents first and keep the PC plugged in throughout. Read each screen carefully during these tools, because the wrong choice can erase files, and stop if anything asks you to format a drive unexpectedly.

When to seek help or reinstall

Consider a repair install, which reinstalls Windows while keeping your files and apps, if updates have failed for weeks, the system is unstable, or you see repeated blue screens. A full clean install is the last resort: it wipes everything, so only do it after a complete backup to an external drive or cloud storage, and after writing down your app licences and passwords. If the PC is still under warranty, or the drive shows errors in a disk health check, contact the maker or a repair shop first, because a failing drive can look exactly like a stuck update.

Prevent the next stuck update

Keep at least 20 percent of your drive free, restart your PC at least once a week, install updates promptly rather than letting dozens pile up, and avoid switching the PC off during updates. Set active hours in Windows Update so restarts do not interrupt your work, and keep a backup routine running in the background. Updates are annoying when they stall, but they are also how security holes get closed, so the goal is a system that updates smoothly, not one that never updates at all.

Quick checklist

Wait patiently, restart properly, note the error code, run the troubleshooter, free up space, clear the update cache, update drivers, pause and retry, and only then try a manual download. Work in that order, back up before any reinstall, and never force a shutdown in the first hour of an update unless the PC is completely frozen.

Frequently asked questions

How long should I wait before calling an update stuck? Wait at least an hour for a normal update and two hours for a major feature update, with the PC plugged in. A percentage that looks frozen is often still working in the background.

Will restarting during an update break Windows? Restarting through the Start menu is usually safe, and Windows often rolls the update back and boots normally. Only hold the power button if the PC has been completely unresponsive for several hours, because switching off mid-update can corrupt the installation.

What if the same update keeps failing? Write down the error code, clear the update cache as described above, and try again. If it still fails, download that update manually from the Microsoft Update Catalog using the update number.

Will I lose my files if I reinstall Windows? A reinstall can remove apps and settings, so back up your files first, even if you choose the option that keeps personal files. Never reinstall without a backup.
