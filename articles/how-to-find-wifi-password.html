How to Find Your Wi-Fi Password

You need the Wi-Fi password for a new device, but nobody remembers it, and it is not written anywhere obvious. The good news is that any device already connected to the network can usually show it to you, and if none can, the router itself holds the answer. Try these methods in order, starting with the easiest, and you will almost always find it without resetting anything.

Before you start: use your own network only

These steps are for recovering the password of a Wi-Fi network you own or are authorised to use, such as your home or office network. If you are setting up a guest's device on your own network, all of these methods are perfectly fine, and the router method at the end works even when no device can show the password. If it is a work network, ask your IT team rather than trying to work around their controls, because work networks often restrict password viewing for good reason.

1. Find it on a Windows PC

On a Windows PC already connected to the network, open Settings, then Network and internet, then Wi-Fi, then Manage known networks. Click the network name, then Properties, and look for the security settings. On older Windows versions, open Control Panel, then Network and Sharing Center, click the Wi-Fi network name, then Wireless Properties, then the Security tab, and tick Show characters to reveal the password. You will need administrator permission on the PC, so if it is a work computer, ask IT instead of trying to bypass the restriction. Write the password down somewhere safe once you have it, because you will need it again.

2. Find it on a Mac

On a Mac, open Keychain Access from Applications, then Utilities, or use the newer Passwords app on recent macOS versions. Search for the Wi-Fi network name, double-click it, and tick Show password. You will be asked for your Mac user password or fingerprint to confirm. This is a sensible security check, and it means someone who picks up your unlocked Mac cannot simply read every saved password. If you use iCloud Keychain, the same password may also be available on your iPhone, which brings us to the next method.

3. Find it on an Android phone

On most Android phones, go to Settings, then Network and internet, then Wi-Fi, and tap the connected network. Tap Share, confirm with your fingerprint or PIN, and the phone will show a QR code. On many phones the password is printed in plain text below that QR code. If it is not, another phone can scan the QR code to join the network without typing the password at all. This is a handy trick for guests: you do not even need to read the password aloud, which avoids the usual mishearing of similar-looking characters.

4. Find it on an iPhone

On an iPhone running a recent version of iOS, go to Settings, then Wi-Fi, and tap the small information icon next to the connected network. Tap the password field and confirm with Face ID, Touch ID or your passcode to reveal it. You can then copy it or share it with a nearby Apple device. If you do not see the password field, update iOS, because this feature arrived in a later version. Older iPhones without it can still get the password from a Mac signed into the same iCloud account, using the Keychain method above.

5. Find it on the router itself

If no device can show the password, the router is the final source. Look for a sticker on the bottom or back of the router; many providers print the original Wi-Fi password there. If the password was changed after installation, that sticker will not help, and you will need to log in to the router. Connect a device to the router, open a browser, and go to the router's address, usually 192.168.1.1 or 192.168.0.1. Log in with the router admin username and password, which are often printed on the same sticker, then look for Wireless settings to see the current password. If you cannot log in, do not factory-reset the router in a panic, because that will disconnect everything and change the password to the sticker value, which may not be what your devices expect.

Common mistakes to avoid

Do not confuse the router admin password with the Wi-Fi password; they are different, and mixing them up is the most common reason people get stuck at the router login. Do not share the password by reading it aloud in a crowded room if you can use a QR code instead. And once you recover it, store it in a password manager or a safe place at home, so you are not doing this again next month.

Frequently asked questions

Can I see the password on a phone that is not connected? Only if that phone previously joined the network and still remembers it. A phone that has never connected cannot show you the password.

Why does Windows ask for admin permission? Because saved Wi-Fi passwords are sensitive. Admin permission stops anyone who picks up your computer from reading them without a check.

What if the sticker password does not work? It means the password was changed after installation. Use a connected device or the router login method instead.

Should I change the password once I find it? Only if you suspect someone uninvited is using your network. Otherwise, keep the one you have and store it safely.
