How to Find Your Wi-Fi Password

You need the Wi-Fi password for a new device, but nobody remembers it, and it is not written anywhere obvious. The good news is that any device already connected to the network can show it to you, and if none can, the router itself holds the answer. Try these methods in order.

Before you start: use your own network only

These steps are for recovering the password of a Wi-Fi network you own or are authorised to use, such as your home or office network. Looking up someone else's password without permission is not something this guide is for. If you are setting up a guest's device on your own network, all of these methods are perfectly fine, and the router method at the end works even when no device can show the password.

1. Find it on a Windows PC

On a Windows PC already connected to the network, open Settings, then Network and internet, then Wi-Fi, then Manage known networks. Click the network name, then Properties, and look for the security settings. On older Windows versions, open Control Panel, then Network and Sharing Center, click the Wi-Fi network name, then Wireless Properties, then the Security tab, and tick Show characters to reveal the password. You will need administrator permission on the PC, so if it is a work computer, ask your IT team instead of trying to bypass the restriction.

2. Find it on a Mac

On a Mac, open Keychain Access from Applications, then Utilities, or use the newer Passwords app on recent macOS versions. Search for the Wi-Fi network name, double-click it, and tick Show password. You will be asked for your Mac user password or fingerprint to confirm. The password shown is the one the Mac used to connect, so it is exactly what you need for a new device. If you use iCloud Keychain, the same password is available on your iPhone as well, which brings us to the next method.

3. Find it on an iPhone

On an iPhone running iOS 16 or later, go to Settings, then Wi-Fi, and tap the small information icon next to the connected network. Tap the password field, authenticate with Face ID, Touch ID, or your passcode, and the password will be revealed, with an option to copy it. On older iPhones without this feature, you can still share the password with another Apple device nearby: on the new device, try to join the network, and a prompt will appear on your iPhone asking if you want to share the password. Accept, and the new device connects without you ever seeing the password.

4. Find it on an Android phone

On most Android phones, go to Settings, then Network and internet, then Wi-Fi, and tap the connected network. Tap Share, authenticate with your fingerprint or PIN, and a QR code appears along with the password written underneath it. Another phone can scan that QR code to join the network directly, which is the easiest way to share Wi-Fi with a guest. Samsung phones show the password in a similar place under Wi-Fi settings. If your phone does not show the password option, it may be restricted by the manufacturer, in which case use the router method below.

5. Find it on the router itself

If no connected device can show the password, look at the router. Most routers have a sticker on the bottom or back with the default Wi-Fi name and password printed on it. If the password was changed after installation, that sticker will not help, but the router's settings page will. Connect a device to the router with a cable or over Wi-Fi, open a browser, and go to the router's address, commonly 192.168.1.1 or 192.168.0.1. Log in with the admin username and password, which are also on the router sticker unless changed, then look under Wireless or Wi-Fi settings for the password field.

6. Reset the router only as a last resort

If you cannot log into the router either, the last option is a factory reset: press and hold the small reset button on the back of the router for about ten seconds with a paperclip. This restores the default Wi-Fi name and password from the sticker, but it also erases any custom settings, such as a changed admin password, port forwarding, or parental controls. You will need to set those up again, and every device in the house will need to reconnect. Treat this as a last resort, and write the new password down somewhere safe afterwards, so you do not have to do this again.

7. Save it properly for next time

Once you recover the password, store it in a password manager, or write it on a card kept with the router. If you use a password manager on your phone, add a note with the Wi-Fi name and password so anyone in the household with access can find it. Avoid sticking the password on the fridge or in a photo album, where visitors might see it. A good habit is to change the Wi-Fi password once a year and update the stored copy at the same time, which keeps old devices and former guests from staying connected indefinitely.

8. What to do if the password does not work

If a recovered password is rejected by a new device, double-check for mistakes: Wi-Fi passwords are case-sensitive, and the characters 0 and O, or 1 and l, are easy to confuse. Try typing it slowly, or copy and paste it from the phone that revealed it. If it still fails, the password may have been changed since that device last connected, or the router may be blocking new devices. In that case, log into the router and check the current password directly, rather than trusting an older copy stored on a device.

Final checklist

Check a connected Windows PC, Mac, iPhone, or Android phone first, since one of them can usually reveal the password in under a minute. If none can, check the router sticker, then the router settings page. Reset the router only as a last resort, and store the recovered password in a password manager so the next new device is painless.

Frequently asked questions

Can I see the password for a network I am not connected to? No. A device only stores the password for networks it has joined, so you need at least one connected device, or access to the router, to recover it.

Is sharing Wi-Fi with a QR code safe? Yes, for guests you trust. The QR code contains the same password, so anyone who scans it can join and can also share it further, so only share it with people you trust with your network.
